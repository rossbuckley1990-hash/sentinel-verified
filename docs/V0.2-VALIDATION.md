## Evaluation and remaining limits

- [Public case study](PUBLIC-EVALUATION.md): **9/9 predeclared outcomes** and **9/9 semantic replays** matched. Five of six defective candidate/contract combinations were signalled; one deliberately inadequate contract missed the real whitespace defect. Two correct candidates were accepted.
- Conventional Mocha and trustbut reproduced two regressions already covered by upstream tests. trustbut also warned about removed assertions. SENTINEL reproduced an additional historical whitespace defect class from an independently approved oracle. Stryker killed 22/24 mutants but did not establish the missing whitespace expectation. These are complementary capabilities, not a superiority ranking.
- [Information-retention experiment](HANDOFF-COMPARISON.md): a prescribed receiver needed one function execution when the saved counterexample was retained, versus eight when an incomplete summary omitted it. An informative summary and reversed search order each needed one. Three deterministic trials measure retained information, not model productivity or human effort.
- [Live Docker probes](ISOLATION.md): four tests passed. Executed probes could not write the image/root or read-only input, read a host-only environment secret, or reach the network. Docker isolates verification only; its reviewed image, daemon and host kernel/VM remain trusted.
- The complete v0.1 automated suite was run successfully before changes. A real existing v0.1 checkpoint, including its two receipts, was read successfully by v0.2 without rewriting it. Schema-1 contracts remain supported; schema-2 interactive approval binds its reviewed baseline and proposal.
- Dependency audit found **zero reported production vulnerabilities** at measurement time. This is a registry advisory check, not a security proof.

## Failures found and repaired

Adversarial review exposed and added coverage for specific-intent questions being cleared by an unrelated example; corrupt or cross-repository session pointers; imported session-ID handling; interactive approval reused with a different baseline; an earlier success masking a later failed verifier attempt; missing unresolved intent in initial handoff context; live orphan-agent recovery; unloadable suites being treated as empty coverage; and Vitest caches attempting writes beside read-only container dependencies. Pre-consent Git inspection disables hooks/fsmonitor and lazy fetches, and avoids status/filter execution. Further review covered ambiguous trailing alternatives in natural-language examples and expected-value edits retaining an earlier proposal identity. The public harness's first archived-dependency layout was also incorrect and failed explicitly before being repaired. Timeout attempts under severe unrelated host load are retained and excluded from successful detection totals.
