## Defects found during engineering

- A patch destination inside the evidence store was correctly refused; the demo now exports outside protected storage.
- Preservation checks alone could certify a change objective in schema3. Explicit preservation-only intent and regression tests now distinguish refactor tasks from unspecified changes.
- Git metadata-only commits could count as repair progress. Retry progress now compares source file manifests.
- A launcher exited 7 while an inherited-stdio HTTP child kept serving; the verifier previously waited for pipe closure. It now tracks process exit separately and records environment failure.
- Malformed JSON could collide with a diagnostic-shaped expected object. Parsing errors are now contradictions with explicit parse evidence.
- A self-consistent imported bundle could label non-PNG bytes as a screenshot. Import validates the PNG signature before publishing state.
